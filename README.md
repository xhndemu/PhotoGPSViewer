# PhotoGPSViewer

一个轻量级的 Windows 桌面应用：打开照片文件夹，在地图（高德 / 天地图）上查看每张照片的 GPS 位置和拍摄方向。

## 使用方法

1. 解压后双击 `PhotoGPSViewer.exe` 运行（**首次启动较慢，约 5-10 秒**）
2. 点击工具栏「浏览文件夹…」选择包含照片的文件夹
3. 在左侧列表中选择一张或多张照片
   - **单击**：显示单张位置和拍摄方向三角形
   - **Ctrl + 单击**：多选
   - **Shift + 单击**：范围选择
4. 点击工具栏「📌 标注选中」把当前选中的图钉到地图上（再选别的再点会替换）
5. 点击「✕ 清除标注」移除所有钉
6. 点击地图右上角可切换图层：高德地图 / 高德卫星 / 天地图 / 天地图影像
7. **点击地图上的标记**可跳转到对应照片
8. 工具栏「⚙ 设置」用于配置天地图 Token（仅使用天地图时需要）

## 配置天地图 Token

天地图需要免费 token，否则只能看到高德图层。

1. 访问 http://lbs.tianditu.gov.cn/ 注册并创建应用（应用类型选「浏览器端」即可）
2. 复制 token
3. 在 PhotoGPSViewer 中点击工具栏「⚙ 设置」，粘贴 token，点「确定」
4. Token 保存在 `C:\Users\<你的用户名>\.photo_gps_viewer.cfg`，重启仍然生效

## 支持的照片格式

- `.jpg` / `.jpeg`
- `.tif` / `.tiff`
- `.heic` / `.heif`（内置 pillow-heif 解码，可正常预览；EXIF 中的 GPS 与拍摄方向也能读取）

## 拍摄方向（FoV 三角形）说明

- 读取 EXIF 中的 `FocalLengthIn35mmFilm`（35mm 等效焦距），按全画幅 36mm 计算水平视场角
- 三角形大小随地图缩放自动调整
- 没有方向信息的照片只显示位置点，不画三角形

## 系统要求

- Windows 7 / 8 / 10 / 11（64 位）
- 约 400 MB 硬盘空间
- 网络（首次加载地图瓦片需要联网）

## 数据存储

- 设置：`%USERPROFILE%\.photo_gps_viewer.cfg`
- 照片 EXIF：仅读取，不修改

## 常见问题

**Q: 启动后地图是灰色的？**
A: 检查网络，高德/天地图瓦片需要联网加载。

**Q: 标记位置和地图对不上？**
A: 这是坐标偏移问题。本程序已对高德（GCJ02）和天地图（WGS84）做了自动处理，无需手动设置。

**Q: HEIC 照片显示不出预览？**
A: v0.11 已内置 pillow-heif，理论上 Windows 7+ 都能正常预览。如仍失败，可重新下载 ZIP 解压到新目录后运行（排除旧的 `_internal` DLL 被替换造成的兼容问题）。

**Q: 怎么完全卸载？**
A: 删除 PhotoGPSViewer 文件夹即可，没有任何注册表或系统残留（配置在用户目录 `.photo_gps_viewer.cfg` 可选删除）。
